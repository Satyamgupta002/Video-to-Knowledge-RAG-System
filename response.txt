You asked "why we use CSS Grids?"

 CSS Grid is used to make layouts, which can be a bit confusing with floats and positioning. CSS Grid is one of the ways to create layouts in CSS, and it's especially useful when you want to place items in a grid-like structure.

To learn more about CSS Grid and its usage, I recommend watching the video titled "CSS Grid - Ultimate MasterClass" (Video #29). 

In this video, the speaker explains how to use CSS Grid to create a grid-like structure, and provides examples of how to apply CSS Grid to real-world scenarios. You can watch this video at timestamp 37:56 (HH:MM:SS) where the speaker starts explaining CSS Grid.

Additionally, the speaker also explains why they avoid using floats and clears, and how CSS Grid can be used as an alternative. You can find this information in the same video.
